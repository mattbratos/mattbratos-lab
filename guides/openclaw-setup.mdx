## dependencies

now we have to install all the things openclaw needs to work 



### xcode & xcode cli tools

go to the app store on you mac and just download xcode 

### homebrew

if you don't have [homebrew](https://brew.sh), get it now:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Verify it works:

```bash
brew --version
```

### Git

macOS comes with Git, but let's get the latest version:

```bash
brew install git
```

Set up your identity:

```bash
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

### Node.js

install Node.js using Homebrew:

```bash
brew install node
```

verify:

```bash
node --version
npm --version
```

### pnpm

pnpm is a fast, disk-efficient package manager. Install it:

```bash
npm install -g pnpm
```

Verify:

```bash
pnpm --version
```

### Cursor

some kind of a coding editor might be usefull I'm going with [cursor](https://cursor.com/) 

```bash
brew install --cask cursor
```

Now we need some coding cli, I'm going with claude for vibes and thinging and codex for coding abilities 

### claude code

```bash
npm install -g @anthropic-ai/claude-code
```

Run it for the first time to set up authentication:

```bash
claude
```

Follow the prompts to log in.

### Codex

Install OpenAI's Codex CLI:

```bash
npm install -g @openai/codex
```
