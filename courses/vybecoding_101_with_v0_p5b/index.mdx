This is a super simple, hands-on course to help complete beginners start creating with **v0 by Vercel**. You will go from “What is v0?” to building and sharing a basic page.

## Who this course is for

- You have **never** used v0 before
- You might not know how to code, or only know a little
- You want to quickly **see results** without complex setup
- You like to **learn by doing**

## What is v0 (in plain language)

v0 is an **AI-powered UI builder**. You:

1. Describe what you want in **simple text** (a "prompt")
2. v0 generates a **web page layout and code** for you
3. You can **edit, refine, and export** the result

You don’t need to understand all the code to get value. You’ll start by using v0 like a creative assistant.

## Course structure

This course has **one module** with **three short chapters**:

1. **Welcome to v0**  
   - Create your v0 account  
   - Learn the basic layout of the v0 interface  
   - Understand what prompts are and where to type them

2. **Build your first page**  
   - Write a simple prompt  
   - Generate a basic landing page  
   - Make small edits with clicks and text

3. **Share and iterate**  
   - Save and name your project  
   - Share it with a link  
   - Improve the design with better prompts

## Prerequisites

You only need:

- A modern web browser (Chrome, Edge, Safari, Firefox)
- An internet connection
- A basic understanding of using websites (click, type, scroll)
- An email or GitHub account to sign in to v0

## Learning outcomes

By the end of this course, you will be able to:

- Open v0 and feel **comfortable** with the main screens
- Use **simple prompts** to generate UI layouts
- Make **basic edits** to text, colors, and layout
- **Save** your work and **share** it with others
- Know how to keep **improving** your pages over time

## How to use this course

- Follow the chapters **in order**
- Do the **hands-on steps** as you read
- Don’t worry about perfection—focus on **trying things**
- If something looks different on your screen, pause and explore; v0 updates often

When you’re ready, jump into the first module: **01 – v0 Basics**.
